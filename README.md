# УСИЛЕНИЕ ПРО — прототип мультилендинга

Прототип сайта (сгенерирован в Google Stitch, доработан вручную): статический HTML + Tailwind CDN + Google Fonts,
без сборки. Единый дизайн-токен (см. `DESIGN.md`).

## Структура

- `index.html` — главная (общий инженерный аудит)
- `chastnye-doma.html` — сегмент B2C (частные дома)
- `biznes-i-sklady.html` — сегмент B2B (бизнес, склады, промышленность)
- `gossektor-i-mkd.html` — сегмент B2G (МКД, соцобъекты, госзаказ)
- `diagnostika.html` — диагностика и мониторинг (георадар, лазерное сканирование)
- `tehnologiya.html` — технология геополимерного инъектирования
- `assets/logo.svg` — логотип (взят из content/site/assets)

Навигация в шапке между этими 6 страницами связана реальными ссылками.
Пункты футера "Технические регламенты" и "Политика конфиденциальности" пока без страниц (href="#").

## Известные ограничения (требуют доработки перед боевым запуском)

- Формы (`#audit-form`, калькуляторы) — только вёрстка, без обработчика отправки (нужен backend/сервис форм).
- Нет реальных страниц для регламентов и политики конфиденциальности.
- Контент не сверялся построчно с `knowledge-base/` — проверить цифры (гарантии, сроки, цены) перед публикацией.
- Стили тянутся с Tailwind CDN и Google Fonts во время выполнения — для продакшена стоит собрать статический CSS.

## Локальный просмотр

Просто открыть `index.html` в браузере — сборка не нужна.
